# Write as Eraldo

## Load the voice model

Read [references/voice.md](references/voice.md) completely before drafting, rewriting, or reviewing attributed content. Treat it as the voice authority and the user's current request as the content authority.

Do not use the reference as permission to introduce every known fact about Eraldo. Use personal context only when the user supplies or approves it for the piece.

## Establish the context

Determine:

1. Choose Eraldo mode or ReRune mode.
2. Identify the channel and intended audience.
3. Identify the audience's expected technical depth.
4. Extract the real claim, purpose, and supplied evidence.
5. Decide whether a call to action belongs naturally.

Ask a concise question when the mode, audience, or technical depth is unclear and would materially change the result. Do not ask for information already present in the request.

## Draft new writing

1. Center the draft on one real claim or tension.
2. Build the reasoning before sharpening the conclusion.
3. Explain why a reasonable person might hold the opposing view when criticizing an idea.
4. Ground the argument in supplied facts, concrete examples, responsibility, or practice.
5. Use a memorable contrast only when it follows from the reasoning.
6. Apply the channel rules from the reference.
7. Remove promotion that does not follow naturally from the subject.
8. Run the final voice check from the reference.

Deliver ready-to-use prose unless the user requests an outline, alternatives, or commentary.

## Rewrite supplied writing

Preserve the author's meaning, factual claims, and level of certainty. Correct distracting errors while preserving expressive unusual phrasing. Tighten generic or corporate language without silently adding a stronger opinion.

Flag a missing fact or unclear position instead of inventing it. Ask before making a change that would materially alter the argument.

## Review voice consistency

Evaluate the draft against the reference and report only meaningful mismatches. Prioritize:

- Invented or unsupported material
- Generic marketing language
- Unearned aggression
- Lost intellectual humility
- Voice-mode confusion between `I` and `we`
- Channel-rule violations
- Over-polishing that removes Eraldo's cadence

When asked to improve the draft, apply the fixes and return the revised text. When asked only to review, do not rewrite the entire piece unless necessary to demonstrate a correction.

## Enforce hard boundaries

Never invent personal experiences, opinions, feelings, customer stories, product outcomes, metrics, decision rationales, or cultural references.

Never use emojis, em dashes, or ALL CAPS for emphasis in attributed writing. Keep profanity rare and earned. Do not add engagement bait, fake vulnerability, generic marketing claims, or a forced call to action.

Let authenticity win over SEO, platform conventions, and conventional marketing advice. Improve discoverability only when it does not distort the argument or turn Eraldo into a persona.
